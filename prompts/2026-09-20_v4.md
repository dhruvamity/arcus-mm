## 2. WS-L: Deep historical screening (start immediately, runs in parallel, blocks nothing)

**Purpose:** use Arcus's real retroactive history (candles + trade tape) to strengthen the current asset ranking, which right now rests on roughly one weekend of live-recorded data.

**Explicit non-goal, state this in the output so nobody downstream misreads it:** this cannot produce a fill-level backtest. Candle OHLC is oracle-price-derived, not order-book-derived, and Arcus exposes no retroactive `l2OrderBook` history — only the current snapshot. This workstream informs *which markets deserve the recorder's attention and how to interpret their short-window pilot stats*; it does not replace `src/sim/engine.py` replay against recorded L2 data as the source of any PnL claim.

**Tasks:**
1. For every market in `GET /v1/markets`, page `GET /v1/candles` backward (via `to`/`from`) at `1h` resolution until the API returns empty, to empirically discover actual retention depth per market — do not assume "months" or "years"; some markets may be newly listed. Record the discovered depth per market.
2. From the full available history, compute per market: realized volatility (from oracle-price returns) over the full window and over rolling 7-day windows (regime stability check — is this week typical, or an outlier?); funding rate mean/std/sign-consistency; `tradeCount`/`volume` consistency week over week.
3. Cross-reference against `research/pilot_summary.md`'s existing (short-window) ranking. Where the long-run and short-window rankings *disagree materially* for a given market, flag it explicitly in the output — don't silently prefer one. A market that looked good over one weekend but is a long-run outlier is exactly the kind of thing this workstream exists to catch.
4. Output: `research/deep_history_screen.md`, table-driven, same provenance discipline as every other report (`scripts/verify_report.py` must pass on it, numbers only from computed tables, no unlinked prose claims).
5. Evidence: `scripts/ev.sh V-35 deep_history_pull -- ...` for the pull itself, `scripts/ev.sh V-35 deep_history_crosscheck -- ...` for the disagreement analysis.

This can start the moment this prompt is read. It does not touch the recorder, does not touch any order path, and has zero interaction with the paper-trading workstream below — run it concurrently.
