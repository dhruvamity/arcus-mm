## The one item still genuinely open: V-36 — kappa is hardcoded, `calibrate_kappa_from_trades()` is dead code

Read `src/strategies/avellaneda_stoikov.py` directly. The empirical calibration function is there and looks correctly designed:

```python
def calibrate_kappa_from_trades(df_trades, duration_hours, mean_spread_bps=4.0) -> Tuple[float, Dict]:
    ...
    trades_per_hour = n_trades / duration_hours
    delta_half = (mean_spread_bps / 2.0) / 10_000.0
    raw_kappa = math.log(max(1.0, trades_per_hour)) / max(1e-4, delta_half * 100.0)
    fitted_kappa = max(0.1, min(50.0, raw_kappa))
    return fitted_kappa, {...}
```

But `scripts/run_pilot_analysis.py`, line 227–229, is where every pilot run actually instantiates the strategy — and it never calls that function:

```python
"Avellaneda_Stoikov": AvellanedaStoikovStrategy(
    market=market, tick_size=tick, step_size=step, gamma=0.1, kappa=1.5, clip_notional=clip_notional
),
```

`kappa=1.5` is the class's own hardcoded placeholder default, passed explicitly here, every time, for every market. It is never replaced with a fitted value. That's the entire reason every single market shows `NOT TUNABLE` with 0 fills in `pilot_summary.md` — it isn't a finding about the market or the strategy family, it's an unwired constant.

**Confirming the math, so this isn't just "check it later":** with `gamma=0.10` and `kappa=1.5`, the spread term `(2/gamma) * ln(1 + gamma/kappa) = 20 * ln(1.0667) ≈ 1.29`. That's a spread of ~129% of the mid-price — quotes that far from the market will never, ever fill, on any asset, at any volatility. A properly fitted kappa from real trade data (using the function above, on the same trade tape `run_pilot_analysis.py` already parses per market) would come out orders of magnitude larger — a rough hand-check with plausible trade rates puts fitted kappa in the hundreds, which brings the spread term down to a sane few basis points.

### Fix

In `scripts/run_pilot_analysis.py`, at the market-level loop (same place `trades_per_hour` and `duration_hours` are already computed for the pilot table), call `calibrate_kappa_from_trades()` on that market's parsed trade data before constructing the strategy, and pass the result through:

```python
fitted_kappa, kappa_meta = calibrate_kappa_from_trades(
    df_trades_for_market, duration_hours, mean_spread_bps=observed_spread_bps
)
"Avellaneda_Stoikov": AvellanedaStoikovStrategy(
    market=market, tick_size=tick, step_size=step, gamma=0.1,
    kappa=fitted_kappa, is_calibrated=kappa_meta["is_calibrated"], clip_notional=clip_notional
),
```

Use the market's own observed spread (already available from the pilot data) for `mean_spread_bps` rather than the 4.0 default, so the calibration is self-consistent with what's actually being quoted.
